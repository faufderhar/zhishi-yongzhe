# 美术素材（替换说明）
正式美术到位后，直接用**同名文件**覆盖即可，代码无需改动（映射在 src/game/characters.ts）。
- pups/pup_*.png：小狗救援队（幼儿园+初一），透明底，由 tools/cutout_pups.py 从 /workspace/art/characters/pups/*.jpg 抠图生成
- chars/char_*_sprite.png：高一科幻角色（复制自 /workspace/art/characters）
- monsters/mon_[k|j|h]_*_sprite.png：怪物，k=幼儿园 j=初一 h=高一（复制自 /workspace/art/monsters）
建议尺寸：最长边 512px，透明 PNG/WebP。
